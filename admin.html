Administración del catálogo

¿Cómo consigo el token?
  1. Entra a github.com con la cuenta dueña del repositorio.
  2. Toca tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Nombre: Merina admin. Vencimiento: el más largo que permita.
  4. En Repository access elige Only select repositories y marca merina.
  5. En Permissions → Repository permissions pon Contents: Read and write.
  6. Toca Generate token y copia el texto que empieza con github_pat_. Solo se muestra una vez.

El token funciona como una llave: no lo compartas ni lo publiques.
