# Merina · Perfumería

Página web estática (HTML + CSS + JS) con panel de administración.

## Estructura
- `index.html`       → la página pública
- `admin.html`       → panel para agregar, editar, eliminar perfumes y marcar agotados
- `data/catalogo.js` → el catálogo y los datos del negocio (lo escribe el panel)
- `img/`             → fotos de los perfumes (las sube el panel)
- `css/`, `js/`      → diseño y lógica

## Probar en tu computadora
Doble clic en `index.html`. (El panel necesita el repositorio en GitHub para guardar.)

## Publicar y administrar
Ver las instrucciones en la conversación: subir a GitHub, activar Pages
y entrar a `https://TU-USUARIO.github.io/merina/admin.html` con el token.
